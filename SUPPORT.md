# Support

For questions, bug reports, and feature requests, use GitHub Issues.

When reporting scan or cleanup behavior, include:

- macOS version
- Whether the build came from source or a packaged download
- The folder type scanned, such as Downloads, home folder, external volume, or another user-selected folder
- Whether Full Disk Access was granted
- A short description of what you expected and what happened

Do not post private file paths, personal document names, file contents, signing files, provisioning profiles, or scan output that contains sensitive local information.
