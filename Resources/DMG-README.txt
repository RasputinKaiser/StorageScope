StorageScope

Drag StorageScope.app to Applications, then launch it from Applications.

StorageScope is a local-first storage explorer. It uses the macOS folder picker
for access, stores app-scoped bookmarks for recent scans, and does not upload
file names, paths, contents, hashes, or analytics.

If this build is not Developer ID signed and notarized, macOS may ask you to
confirm that you want to open it. For public direct distribution, Developer ID
signing and notarization are recommended.
