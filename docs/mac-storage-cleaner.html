Open-source Mac storage cleaner

StorageScope is a Mac storage cleaner for people who want review-first cleanup instead of black-box deletion. It helps find large folders, stale files, duplicate candidates, caches, installers, archives, disk images, and build artifacts.

How to plan Mac storage cleanup

  1. Scan the folders you care about — StorageScope separates verified duplicate reclaim, review-suggested cleanup, and access gaps into different lanes.
  2. Mark cleanup candidates and review the risk disclosure on each batch; mixed-confidence batches spell out what is uncertain before you act.
  3. Confirm a batched, transactional move to Trash — earlier moves roll back if a later one fails, and nothing is silently deleted.

Cleanup is review-first

  • Verified duplicate reclaim is separated from review-suggested cleanup.
  • Mixed-confidence cleanup batches disclose risk before anything changes.
  • File actions use Finder, copy path, open, or Move to Trash instead of silent deletion.
  • Transactional cleanup batches can roll back earlier moves if a later move fails.

Built for local Mac storage cleanup

StorageScope uses macOS folder permission flows and keeps scan data local. It is aimed at Mac users who want to understand storage pressure before reclaiming space.
