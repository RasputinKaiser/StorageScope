Free macOS disk space analyzer

StorageScope helps Mac users find what is taking up disk space without uploading scan results, file names, paths, or hashes. It is an open-source SwiftUI/AppKit app for disk usage analysis, large folder scanning, stale file review, and cleanup planning.

How to find what's using disk space

  1. Pick folders to analyze (home folder or a volume); access is saved as a security-scoped bookmark for next launch.
  2. Run the scan — StorageScope ranks the largest folders, old large files, file types, caches, and duplicate candidates locally, with no scan data leaving your Mac.
  3. Drill in via the tree, inspector, and search to triage what's worth reclaiming before any cleanup action.

What it analyzes

  • Largest folders and files
  • Old large files that may be worth reviewing
  • File type usage across scanned folders
  • Caches, build artifacts, installers, archives, disk images, and temporary-looking files
  • Duplicate candidates that can be verified before cleanup

Why local-first matters

StorageScope runs scans against folders the user grants through macOS folder selection or security-scoped bookmarks. The app is built for people who want a storage analyzer they can inspect, build, and run without sending private file metadata to a service.
