Open-source CleanMyMac alternative

StorageScope is for Mac users who want an open-source alternative to black-box cleaner apps. It focuses on local disk space analysis, duplicate file review, large folder scanning, and cleanup planning that the user can inspect before taking action.

How StorageScope stays transparent

  1. Read the source — every line of the scanner, duplicate verifier, and Trash mover is MIT-licensed on GitHub.
  2. Run locally — scans use macOS folder access and security-scoped bookmarks, with no uploads of names, paths, hashes, or identifiers.
  3. Clean up on your terms — batches go to Trash (not permanent deletion) and roll back on partial failure, so you can always undo.

StorageScope focuses on transparency

  • Open-source SwiftUI/AppKit codebase under the MIT License.
  • Local-first scans with no uploaded scan results, file names, paths, hashes, analytics, or identifiers.
  • Review-first cleanup planning for large files, caches, installers, archives, and duplicates.
  • macOS Trash-based cleanup actions instead of silent permanent deletion.

Not a one-click cleaner

StorageScope is built to show storage pressure and help the user decide what to reclaim. It is better suited for people who want to inspect cleanup targets than people who want an automatic one-click cleaner.
